## 🏅 How we rank

Every project gets a score out of 100 from the signals below. A signal we cannot measure yet is left out and its weight goes to the others, so nobody loses points for things we have not checked. The score sets the order; 🥇🥈🥉 mark the top three places in each table.

| Signal | Weight | What it looks at | Shown as (80+ · 50+ · 30+ · lower) | Status |
|---|--:|---|---|:-:|
| ⭐ Adoption | 15% | GitHub stars, log-scaled, ranked half within the category and half across the list | widely used · popular · known · niche | live |
| 📈 Momentum | 10% | stars gained in the last 30 days, ranked within the category | surging · rising · steady · flat | soon |
| 🕒 Freshness | 15% | last commit (full marks under 90 days, zero at a year) and last release | active · recent · slowing · quiet | live |
| 🔧 Maintenance | 15% | issues closed vs opened, release cadence, commits in 90 days | healthy · fair · patchy · weak | live |
| 🚀 Easy to run | 20% | apps and tools: a way to install it (Docker, pip, npm, binary, script, Helm or a release download); starters: GitHub template; both: one-click deploy, arm64, healthcheck. Not scored for libraries, plugins, models and collections | very easy · easy · some setup · hard | live |
| ✅ Verified build | 10% | we start it in CI and wait for a healthy response | passes · untested · fails | soon |
| 📖 Docs | 5% | install section, environment docs, upgrade notes | thorough · good · thin · missing | soon |
| 🤖 Agent-ready | 5% | CLAUDE.md, AGENTS.md, skills, llms.txt | ready · partly · minimal · none | live |
| 🔒 Privacy | 5% | no telemetry or opt-out, works fully offline | private · mostly private · some telemetry · leaky | soon |

<sub>Penalties: no license −10. Coming: data must leave your host −10 · star-growth anomaly −15 · unpatched security advisory −20. Archived projects are removed. Paid placements never touch the score.</sub>

<sub>The weights are our judgment, not science. Think one is wrong? [Tell us](https://github.com/archestack/best-of-ai/issues/new/choose). Method changes: 2026-10-13: Maintenance weighs 15% (was 10%) and Momentum 10% (was 15%), so steady upkeep counts more than a burst of stars · 2026-10-12: penalties we do not check yet are marked coming; only "no license" has ever been applied · 2026-10-09: Docker alone earns no points, medals mark places 1–3 instead of score bands.</sub>

## 🧠 How this works

- 🧠 **On this list:** open-source projects whose main job is AI, from apps you run to libraries you build with. Tools for coding with AI, starters and the stack you ship on live on the sister list, Best of Vibe Coding.
- 🔎 **Found** in curated lists, app stores and template galleries, then fact-checked on GitHub: stars, last commit, license, Docker files.
- ✍️ **Written from the README**, never copied from other lists: what it does, what it needs, strengths and weaknesses as claims you can check. Specs say `unknown` rather than guess.
- 🔄 **Kept fresh**: entries are rewritten when the README or the latest release changes; projects quiet for 12 months get marked stale, archived ones drop off.
- 🚫 **No pay-to-rank.** Sponsors and affiliate links, if any, are labeled and never touch the order.
